# Iris Game — Chibi Anime Edition

Esta documentación corresponde a la integración de cuatro personajes: `jacky`, `ximena`, `lucy` y `valeria`. Consulta `README-IRIS-GAME-FINAL.md` para el detalle de funciones, ejecución y validaciones.

Los avatares se dibujan por capas en Canvas 2D; no se utilizan rutas de imágenes que no existan dentro del proyecto. La apariencia de Lucy se interpreta desde la descripción escrita recibida porque no se encontró una fotografía de referencia dentro de los ZIP.

La interfaz incluye controles separados para música ambiental generada con Web Audio y efectos de interfaz.

Para iniciar:
```bash
docker compose up --build
```
Abrir `http://localhost`.
